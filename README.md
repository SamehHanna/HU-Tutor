# HU Tutor

A Python-based AI tutoring command based application with speech capabilities.

## Project Structure

- **speech.py** - Speech processing and audio handling functionality
- **tutor.py** - Main tutoring application logic

## Features

- Interactive tutoring interface
- Speech recognition and processing capabilities
- Audio handling for voice-based interactions

## Setup

1. Ensure Python is installed on your system
2. Install required dependencies
3. Run the tutor application

## Usage

```bash
python tutor.py
```

## Requirements

- Python 3.x
- whisper - Speech recognition
- edge_tts - Text-to-speech synthesis
- ollama - LLM integration
- sounddevice - Audio recording
- soundfile - Audio file handling

### Install Dependencies

```bash
pip install openai-whisper edge_tts ollama sounddevice soundfile
```
